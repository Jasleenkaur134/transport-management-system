Transport Management System

This is a web-based Transport Management System developed for managing truck bookings and transport-related activities.

About the Project

The system allows users to create an account, log in, and book trucks by providing pickup, delivery, weight, and other required details. The booking price is calculated automatically.

An admin panel is also included where the admin can view bookings and approve or reject them. Users are notified through email when their booking status changes.

Features
User Signup/Login
Truck Booking
Automatic Price Calculation
User Dashboard
Booking History
Admin Panel
Approve/Reject Bookings
Email Notifications
Technologies Used

HTML CSS JavaScript Bootstrap EJS
Node.js Express.js MongoDB Mongoose

Installation
git clone <your-repository-link>
cd transport-management-system
npm install

Open http://localhost:3000 in your browser.
